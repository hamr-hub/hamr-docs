# 安全架构

HamR 以隐私优先为核心设计原则，采用多层安全防护确保家庭数据安全。

## 核心防护

- **端到端加密**：所有通信使用 TLS 1.3 加密，敏感数据使用 AES-256 加密存储。
- **零知识架构**：私有部署模式下，服务提供方无法访问用户数据。
- **隐私优先**：最小数据收集原则，不跟踪用户行为，不出售数据。
- **细粒度权限**：RBAC 权限模型，家庭成员按角色获得不同访问权限。

## 认证与授权

```
认证流程：
  用户 → OAuth2.0 / 邮箱+密码 → 账号服务 → JWT Token
    │
    ├── Access Token (15 分钟有效)
    └── Refresh Token (7 天有效，HttpOnly Cookie)
```

### 权限模型（RBAC）

| 角色 | 数据读取 | 设备控制 | 家庭管理 |
| ---- | -------- | -------- | -------- |
| 管理员 | ✅ 全部 | ✅ 全部 | ✅ |
| 成人成员 | ✅ 全部 | ✅ 全部 | ❌ |
| 青少年 | ⚠️ 受限 | ⚠️ 受限 | ❌ |
| 访客 | ❌ | ⚠️ 受限 | ❌ |

## 数据安全

- **传输加密**：TLS 1.3，HSTS 启用，证书自动续期。
- **存储加密**：PostgreSQL 透明数据加密 (TDE)，敏感字段 AES-256-GCM 加密。
- **密钥管理**：主密钥存储在环境变量中，支持 HashiCorp Vault 集成。
- **备份加密**：备份文件使用 GPG 加密，异地备份使用 AES-256 加密传输。
- **日志脱敏**：日志中自动脱敏 PII 数据（姓名、邮箱、手机号、地址）。

## 安全报告
